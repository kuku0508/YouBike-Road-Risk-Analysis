## 6. 建議第一個實際小任務（未執行）

**M0：一個月 YouBike 租借資料的唯讀盤點與 schema audit。**

- 目標：先確認原始檔到底長什麼樣、是否可建立 OD，以及月份是否完整。
- Input：優先一個可取得的 2023/01 原始月檔、來源網址、取得日期；若該月不可得，明確記錄替代月及原因，不隱藏缺月。
- Process：記錄檔名、bytes、SHA-256、格式／編碼、實際欄名與推定型態；先有界預覽識別粒度，再串流盤點全檔筆數、時間範圍、解析失敗、必要欄位缺失、每日筆數、疑似重複。報告問題但不刪除、補值或改寫原檔。
- Output：小型 `src/` audit 模組、`notes/data-audit.md` 與 `data/interim/raw_manifest.parquet`。依賴只加實際使用的套件；原始逐列內容不放 README 或 commit。
- 驗證：原檔前後 hash 相同；成功解析＋失敗＝全檔紀錄數（依檔案格式明訂表頭處理）；完整月份由實際日期檢查；驗證來源是一旅次或彙總而非憑檔名假定；以小型自製格式案例檢查解析失敗／缺欄的回報。
- 完成條件：清楚列出能否建立 O→D、尚缺的站點鍵或時間欄，指令可在相同檔案上重跑得到相同摘要，Git staged 無原始資料，再 commit。
- 停止條件：缺檔或缺必要欄位時，交付缺口與取得線索，不進入 M1、不自行改用其他來源冒充原資料。

## 7. 每個模組的 commit gate

記錄 input 指紋、process 設定與 output 路徑；驗證計算不變量與該模組必要的實際樣本／圖面；更新 README 的已完成／未完成與 decisions 狀態；檢查 `git diff --check` 及 staged 名單；僅 commit 本模組成果。原結果比較與新方法敏感度分開呈現，失敗也保留理由。本階段結束於文件 commit，不啟動 M0。
